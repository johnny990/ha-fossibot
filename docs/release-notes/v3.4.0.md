# v3.4.0 — AC Single Charge for protocol V1 stations (F7200)

## ✨ Added

**AC Single Charge** (the app's one-time AC charge, formerly "Charge now").
A switch (state-word bit 11), the `fossibot.set_single_charge` action (holding
36-37: start now or at a time; optional end time; optional energy amount or
target SoC; with no stop condition the charge runs until full) and the
diagnostic sensor **AC Single Charge Setting** that shows the stored setting
as text.

## ⚠️ Notes

- Confirmed against BrightEMS 1.7.8 captures on an F7200: the four settings
  frames are reproduced byte for byte and the on/off toggle is bit 11.
- App 1.7.8 writes the state word as two words; the integration keeps the
  one-word frame of 1.7.0 that the existing switches use.
